\# Unity 2D Platformer Game



基于 Unity 2D Platformer 模板开发的2D横版动作游戏。



\## 技术栈

\- Unity 2022.3 LTS

\- C#



\## 实现功能

\- 角色移动与跳跃

\- 动画状态机（Idle / Jump）

\- 敌人AI与碰撞伤害检测

\- Tilemap 关卡设计

\- Cinemachine 摄像机跟随

\- UI系统（血量/分数/游戏结算）

\- 音效与背景音乐



\## 如何运行

1\. 从 \[Releases](https://github.com/zdh2339038049/Unity-2D-platformer/releases) 下载构建文件

2\. 解压后双击 `PlatformerGame.exe` 即可运行
